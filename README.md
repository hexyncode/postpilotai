# FBAI Project

## Setup

1. Run the relevant setup script for your OS:
   - On Linux/macOS (Fish shell):
     ```sh
     ./setup.sh
     ```
   - On Windows (PowerShell):
     ```powershell
     ./setup.ps1
     ```

2. Start the application:
   - On Linux/macOS (Fish shell):
     ```sh
     ./start.sh
     ```
   - On Windows (PowerShell):
     ```powershell
     ./start.ps1
     ```
